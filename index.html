Recursos

Tudo que você precisa para começar, num lugar só.

Sem configurar dez extensões. Abra a Faísca, escolha um modelo de projeto e comece a escrever código.

Agente que mexe no código

O Claudinho lê, cria e edita arquivos do projeto e roda comandos no terminal. Escritas e comandos pedem a sua aprovação.

Preview ao lado

Veja a página atualizar enquanto digita. Clique num elemento do preview e a Faísca leva você direto para a linha certa do código.

Erros em português

Mensagens como is not defined viram uma explicação simples do que aconteceu e de como resolver.

Modelos de projeto

Landing page, portfólio, loja, blog, painel e app para TV webOS. Cada um já vem com HTML, CSS e JS organizados.

Componentes prontos

Dezenas de componentes HTML, receitas de CSS e trechos de JavaScript aparecem como sugestões enquanto você digita.

Desfazer sem medo

Antes de cada mudança do agente, a Faísca guarda um ponto de restauração. Dá para voltar mesmo depois de fechar e abrir de novo.

Terminal e Git

Terminal integrado e um painel de Git para ver o que mudou, salvar versões e acompanhar o histórico.

Navegação entre arquivos

Ir para a definição, renomear em todos os arquivos e buscar símbolos no projeto inteiro, com os atalhos de sempre.

Claudinho

Um parceiro que explica o que está fazendo.

Peça em português, do seu jeito. O Claudinho planeja, mostra cada ferramenta que usa e para antes de escrever qualquer coisa no seu projeto.

  • Transparente. Você vê cada arquivo lido, cada edição e cada comando.
  • Sob controle. Aprove ou recuse cada escrita. Comandos fora da pasta do projeto são bloqueados.
  • Feito para aprender. Pergunte o porquê de uma linha, peça para comentar o código ou para só apontar o erro sem corrigir.
  • Aceita imagens. Com um modelo de visão, mande um print e peça um layout parecido.

Perguntas

Dúvidas comuns

Preciso saber programar para usar?

Não. A Faísca foi pensada para quem está começando. Os modelos de projeto dão um ponto de partida e o Claudinho explica cada passo. A ideia é você aprender a fazer, não só pedir pronto.

A IA não vai bagunçar meus arquivos?

Toda escrita e todo comando pedem aprovação, e cada mudança gera um ponto de restauração. Se algo não ficar bom, é só desfazer.

Quais linguagens ela suporta?

O editor abre qualquer arquivo de texto e destaca a sintaxe das linguagens mais comuns. Os recursos extras, como preview, componentes e erros explicados, são focados em HTML, CSS e JavaScript.

Funciona em Mac ou Linux?

Por enquanto a Faísca é feita para Windows 10 e 11.

Meu código é enviado para algum lugar?

No modo local, não: tudo roda no seu computador. No modo nuvem, as partes do projeto que o agente lê são enviadas ao provedor do modelo escolhido, para que ele possa responder.
