Recursos

Tudo que você precisa para começar, num lugar só.

Sem configurar dez extensões. Abra a Faísca, escolha um modelo de projeto e comece a escrever código.

Agente que mexe no código

O Claudinho lê, cria e edita arquivos, roda testes e comandos no terminal, pesquisa na internet e olha a página pronta para conferir o visual.

Abre de tudo

Vídeo, áudio, PDF, planilhas, Word e PowerPoint abrem direto na aba. Textos de até 20 MB vão para o editor.

Benchmark de modelos

Teste os modelos da nuvem com o próprio Claudinho em tarefas reais e veja qual acerta mais e responde mais rápido.

Integrada ao Windows

Progresso no ícone da barra de tarefas, notificação quando a IA termina ou precisa de você, zoom com Ctrl + rodinha e ícone na bandeja.

Segura por padrão

Atualizações com assinatura digital, chaves de API cifradas pelo Windows e um agente que não toca em senhas nem credenciais.

Preview ao lado

Veja a página atualizar enquanto digita. Clique num elemento do preview e a Faísca leva você direto para a linha certa do código.

Erros em português

Mensagens como is not defined viram uma explicação simples do que aconteceu e de como resolver.

Modelos de projeto

Landing page, portfólio, loja, blog, painel e app para TV webOS. Cada um já vem com HTML, CSS e JS organizados.

Componentes prontos

Dezenas de componentes HTML, receitas de CSS e trechos de JavaScript aparecem como sugestões enquanto você digita.

Desfazer sem medo

Antes de cada mudança do agente, a Faísca guarda um ponto de restauração. Dá para voltar mesmo depois de fechar e abrir de novo.

Terminal e Git

Terminal integrado e um painel de Git para ver o que mudou, salvar versões e acompanhar o histórico.

Navegação entre arquivos

Ir para a definição, renomear em todos os arquivos e buscar símbolos no projeto inteiro, com os atalhos de sempre.

Claudinho

Um parceiro que explica o que está fazendo.

Peça em português, do seu jeito. O Claudinho planeja, mostra cada ferramenta que usa e para antes de escrever qualquer coisa no seu projeto.

  • Transparente. Você vê cada arquivo lido, cada edição e cada comando.
  • Sob controle. Dentro do projeto ele trabalha direto, e tudo dá para desfazer. Fora da pasta, git push, publicar ou arquivos com senha, ele pergunta antes.
  • Ou com Liberdade total. Quando você quiser, ligue o modo ⚡ e ele faz tudo sozinho naquela conversa, mostrando cada ação no chat.
  • Feito para aprender. Pergunte o porquê de uma linha, peça para comentar o código ou para só apontar o erro sem corrigir.
  • Lê documentos e imagens. Anexe PDF, Word ou planilhas. Com um modelo de visão, mande um print e peça um layout parecido.
  • Pesquisa e confere. Busca na internet quando precisa e tira um print da página para ver se ficou como você pediu.

1.1.3 · novembro de 2026

Ferramentas novas do Claudinho

  • Busca no projeto: acha onde uma função ou texto aparece, com arquivo e linha.
  • Problemas do código: vê os mesmos erros do painel Problemas depois de editar.
  • Servidores em segundo plano: sobe npm run dev sem travar a resposta, lê a saída e para quando terminar.
  • Perguntas no chat com botões de opção quando o pedido é ambíguo, e lista de etapas em tarefas maiores.
  • Git: vê a branch, os arquivos alterados e o diff, sem mexer em nada.

Medidor de contexto

  • Anel com a porcentagem; passe o mouse para ver tokens usados, restantes, a última resposta e o modelo.
  • O total agora é a janela real de cada modelo, em vez de 128 mil para todos.
1.1.2 · novembro de 2026

Liberdade total

  • Botão ⚡ Liberdade total no chat: nesta conversa, o Claudinho faz tudo sem pedir permissão, e cada ação aprovada sozinha aparece no chat.
  • Ligar pede confirmação, e o modo desliga ao trocar de conversa ou reabrir a IDE. Comandos que estragam o Windows e a leitura de senhas e chaves continuam bloqueados.

Segurança

  • Atualizações verificadas: cada instalador e o pacote de voz vêm com assinatura digital (Ed25519) e SHA-256. Arquivo adulterado ou incompleto é recusado antes de rodar.
  • Chaves de API cifradas com o DPAPI do Windows e ocultadas nos logs.
  • O agente não lê pastas de credenciais (SSH, nuvem, navegadores, Windows) nem os dados internos da Faísca.
  • Prévia no celular só na rede local, com sessão por aparelho, limite de tentativas e desligamento automático.

Perguntas

Dúvidas comuns

Preciso saber programar para usar?

Não. A Faísca foi pensada para quem está começando. Os modelos de projeto dão um ponto de partida e o Claudinho explica cada passo. A ideia é você aprender a fazer, não só pedir pronto.

A IA não vai bagunçar meus arquivos?

Antes de cada mudança, a Faísca guarda um ponto de restauração, e o botão Desfazer volta tudo. O que sai da pasta do projeto ou publica na internet pede a sua aprovação, e senhas e chaves o agente nunca lê. Se preferir, nas configurações dá para pedir aprovação para todo comando. Se quiser o contrário, a Liberdade total deixa o Claudinho agir sozinho numa conversa, mostrando cada ação.

Quais linguagens ela suporta?

O editor abre qualquer arquivo de texto e destaca a sintaxe das linguagens mais comuns. Os recursos extras, como preview, componentes e erros explicados, são focados em HTML, CSS e JavaScript.

A Faísca lê as respostas em voz alta?

Sim. Por padrão ela usa as vozes do Windows. Para uma voz mais natural, que roda no seu PC sem internet, abra o painel de voz (alto-falante no topo) e clique em "Baixar voz neural". É um download opcional de cerca de 460 MB, feito uma vez só.

Funciona em Mac ou Linux?

Por enquanto a Faísca é feita para Windows 10 e 11.

Meu código é enviado para algum lugar?

No modo local, não: tudo roda no seu computador. No modo nuvem, as partes do projeto que o agente lê são enviadas ao provedor do modelo escolhido, para que ele possa responder.
